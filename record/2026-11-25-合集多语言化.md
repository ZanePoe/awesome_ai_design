# 2026-11-25 合集多语言化

按 `awesome_ai_video_creation` 已合入的框架移植：英语为默认（仓库根），中文/西班牙语/印地语/法语镜像在 `locales/<lang>/`，共 29 个项目、5 种语言、16 个生成文件。

## 本仓库的特有设计

- `docs/selection.md` 整段内嵌 README 的「如何选择」一节，因此它和 `docs/readme-intro.md` 一样列在 `build.INLINE`，相对链接按语言根目录解析（不是 `docs/` 自身目录）。其余静态文档仍按文件自身目录解析。
- `templates` 有 10 个键（无 `choose`）；`validate()` 保留本仓库原有的 evidence URL 逐字重建断言与 4 个 baseline 仓库集合断言。
- 规范名含 CJK 的 5 个仓库（`open-pencil/open-pencil`、`ZSeven-W/openpencil`、`figma/mcp-server-guide`、`superdesigndev/superdesign`、`penpot/penpot-mcp`）在 en/es/hi/fr 的 `entries.json` 里各给无 CJK 的 `name` 覆盖；缺任一条即 `missing localized display name`。

## 移植时修掉的框架缺陷

1. `anchor()` 用 `str.isalnum()` 判定保留字符，天城文组合符（matra）会被误删；现与 GitHub 实测对齐（见下一节）。
2. `validate()` 与测试里「无汉字」判定各写一套正则（Han 区间 vs `build.CJK`），且 `INLINE` 一度漏掉 `docs/selection.md`；现统一引用 `build.CJK`，`INLINE` 补齐。
3. `data/rankings.csv` 的 `maintenance_status`（中文串）改为 `maintenance_tier`（0–3）。

## README 开头的分类标签导航

每份 README 在 intro 之后、「当前收录」之前新增 `## 分类导航`（en `Jump to a category`、es `Ir a una categoría`、hi `श्रेणी पर जाएँ`、fr `Aller à une catégorie`），按 `ui.json.categories` 顺序一行列出 8 个分类的页内链接，点击跳到对应 `### 分类` 小节；`docs/selection.md` 内嵌的 `## 怎么选` 不计入这 8 个。`anchor()` 按 GitHub 渲染页实测校准（抓取每个 `### 分类` 自带的锚点链接逐一比对）：GitHub 的 README 标题 id 删除 `、`、`.`、`,` 等标点（`设计系统与 DESIGN.md` → `设计系统与-designmd`），保留中日韩文字、带重音拉丁字母与天城文组合符，空格转 `-`；实现即「保留字母/数字/Unicode 组合符（Mn/Mc/Me）/`_`/`-`，其余删除」。中途曾按 npm 包 `github-slugger` 的字符集改成保留 `、`，实测中文分类锚点跳不动，已回退。`scripts/I18N.md` 的 `sections` 键契约已补 `tags`，`tests/test_i18n.py::test_tag_navigation_covers_every_category` 断言导航与 `### ` 小节一一对应。

## 事实与措辞

- 本仓库没有 `record/` 目录，`records_note` 只用行内代码提及 `record/`、不生成链接，`validate()` 也不检查其存在性；本文件是该目录的第一份记录。
- `docs/research.md` 没有字面中文检索关键词表，因此该文件在非 `zh` 语言同样要求零 CJK（`KEYWORD_FILES` 豁免对本仓库不生效）。
- `docs/readme-intro.md` 中文原件自述「中文 AI 设计合集」；英/西/印/法版本不再声称单一语言，其余事实逐句对应，未增删能力声明。
- 译文由模型生成，未经母语者复核；`research/` 台账与本文记录保持撰写时原文。
