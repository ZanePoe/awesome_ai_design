# Awesome AI Design

面向设计师、产品团队和 coding agent 的中文 AI 设计合集。收录可以复用的设计 Skills，可运行的设计 Agent、编辑器和桥接工具，以及能复核研究结论的论文与基准。

这里的“AI 设计”指 Agent 参与界面、原型、矢量图、图解、演示稿、海报等平面图像或设计系统的创建、修改、评审和交接。纯文生图模型、通用 coding agent、无可核验仓库的 SaaS 不作为核心工具收录。官方接入指南和设计系统索引单独标明；已有 [AI 视频合集](https://github.com/ZanePoe/awesome_ai_video_creation) 覆盖视频生成和剪辑。
