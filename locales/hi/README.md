# Awesome AI Design

डिज़ाइनरों, प्रोडक्ट टीमों और coding agent के लिए AI डिज़ाइन का संकलण। इसमें पुनउपयोग-योग्य डिज़ाइन Skills, चलाने-योग्य डिज़ाइन Agent, एडिटर और ब्रिज उपकरण, तथा शोध-निष्कर्षों को दोबारा जाँचने वाले पेपर और बेंचमार्क शामिल हैं।

यहाँ "AI डिज़ाइन" से भाव है UI, प्रोटोटाइप, वेक्टर ग्राफ़िक्स, डॉयाग्राम, प्रस्तुतियाँ या डिज़ाइन सिस्टम के निर्माण, परिवर्तन, समीक्षा और हैंडऑफ़ में Agent की भागीदारी। केवल text-to-image मॉडल, सामान्य coding agent और बिना सत्यापन-योग्य रिपॉज़िटरी वाली SaaS मुख्य उपकरण के रूप में नहीं जोड़े जाते। आधिकारिक ऑनबोर्डिंग गाइड और डिज़ाइन सिस्टम इंडेक्स अलग से चिह्नित हैं; [वीडियो संकलण](https://github.com/ZanePoe/awesome_ai_video_creation) वीडियो जनरेशन और एडिटिंग पहले से कवर करता है।

## कैसे चुनें

- पास कंपोनेंट लाइब्रेरी है और टीम को इंटरैक्टिव प्रोटोटाइप बनाने हैं: पहले [GitHub Replica](https://github.com/github/replica) देखें; यह GitHub Copilot app पर निर्भर है। अपना Agent या मॉडल स्वयं चुनना हो तो [OpenDesign](https://github.com/nexu-io/open-design) देखें।
- पास वेब पेज या डिज़ाइन फ़ाइल है और आगे संपादन करना है: कोड वर्कस्पेस के लिए [Onlook](https://github.com/onlook-dev/onlook) देखें; डिज़ाइन फ़ाइल पढ़ने-लिखने और स्क्रिप्ट-नियंत्रण के लिए [open-pencil/open-pencil](https://github.com/open-pencil/open-pencil) देखें।
- पास पेज है और केवल मोशन या डिज़ाइन गुणवत्ता सुधारनी है: मोशन के लिए [Emil Kowalski Skills](https://github.com/emilkowalski/skills) देखें; लेआउट और एक्सेसिबिलिटी समीक्षा हेतु पहले [Impeccable](https://github.com/pbakaus/impeccable) आज़माएँ, फिर असली ब्राउज़र, कीबोर्ड और असिस्टिव टेक्नोलॉजी से जाँचें।
- ब्रांड-स्टाइल वाली आर्किटेक्चर डायग्राम चाहिए, या Agent को कैनवास पर बार-बार संपादन करना है: क्रमशः [Diagram Design](https://github.com/cathrynlavery/diagram-design) और [Excalidraw MCP Server](https://github.com/yctimlin/mcp_excalidraw) देखें।
- एक ही वाक्य है और संपादन-योग्य PPTX डेक चाहिए: [PPT Agent Skill](https://github.com/Akxan/ppt-agent-skill) देखें; शिप करने से पहले export dependencies और upstream एट्रिब्यूशन जाँचें।
- एक ही विज़ुअल लैंग्वेज कई Agent में दोहरानी है: पहले [DESIGN.md स्पेसिफ़िकेशन](https://github.com/google-labs-code/design.md) से रंग, टाइपोग्राफ़ी और लेआउट नियम लिखें; थर्ड-पार्टी ब्रांड नमूने केवल संदर्भ के लिए हैं।

पहली ट्रायल के लिए एक सार्वजनिक किया जा सकने वाला पेज या डायग्राम चुनें, जाँचें कि डिलीवेबल आगे संपादन-योग्य है या नहीं, फ़ॉन्ट और रिमोट मॉडल के डेटा पथ देखें, फिर उसी इनपुट से विकल्प प्रोजेक्टों की तुलना करें।
