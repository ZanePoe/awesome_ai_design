# Awesome AI Design

डिज़ाइनरों, प्रोडक्ट टीमों और coding agent के लिए AI डिज़ाइन का संकलण। इसमें पुनउपयोग-योग्य डिज़ाइन Skills, चलाने-योग्य डिज़ाइन Agent, एडिटर और ब्रिज उपकरण, तथा शोध-निष्कर्षों को दोबारा जाँचने वाले पेपर और बेंचमार्क शामिल हैं।

यहाँ "AI डिज़ाइन" से भाव है UI, प्रोटोटाइप, वेक्टर ग्राफ़िक्स, डॉयाग्राम, प्रस्तुतियाँ या डिज़ाइन सिस्टम के निर्माण, परिवर्तन, समीक्षा और हैंडऑफ़ में Agent की भागीदारी। केवल text-to-image मॉडल, सामान्य coding agent और बिना सत्यापन-योग्य रिपॉज़िटरी वाली SaaS मुख्य उपकरण के रूप में नहीं जोड़े जाते। आधिकारिक ऑनबोर्डिंग गाइड और डिज़ाइन सिस्टम इंडेक्स अलग से चिह्नित हैं; [वीडियो संकलण](https://github.com/ZanePoe/awesome_ai_video_creation) वीडियो जनरेशन और एडिटिंग पहले से कवर करता है।
