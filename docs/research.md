# Papers and benchmarks

Use these to reproduce experiments or build your own evaluations. The papers below do not join the GitHub maintenance ranking; projects with companion repositories are listed separately in the catalogue's "Papers, benchmarks and datasets" category.

| Study | What it measures | Where to start |
| --- | --- | --- |
| [Design2Code: How Far Are We From Automating Front-End Engineering?](https://arxiv.org/abs/2403.03163) | Generating front-end code from real web-page screenshots, focused on page replication | [Author repository](https://github.com/NoviScl/Design2Code) · [Dataset](https://huggingface.co/datasets/SALT-NLP/Design2Code-hf) |
| [DesignBench: Exploring and Benchmarking MLLMs in Multi-framework Multi-task Front-end Code Generation](https://arxiv.org/abs/2506.06251) | Cross-framework evaluation of generation, editing and repair, not just screenshot replication | [Author project page](https://webpai.github.io/DesignBench/) · [Code and data entry point](https://github.com/WebPAI/DesignBench) |

The two benchmarks differ in tasks, samples and scoring conditions, so their scores cannot be interchanged. The first release did not run the benchmarks and reports no cross-project quality ranking. When evaluating a workbench, you can additionally check editability, interaction states, responsive layout and accessibility; these are not alternative measures of stars.
